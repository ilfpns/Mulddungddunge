# Stage Manager for Windows

macOS 스테이지 매니저를 Windows 10/11에서 구현한 가볍고 빠른 창 관리자입니다.
지금 쓰는 창은 가운데에 두고, 나머지 창은 왼쪽 사이드바에 비스듬히 기울어진 카드로 모아 둡니다.

## 기능

| 동작 | 결과 |
|---|---|
| 사이드바 카드 클릭 / **Alt+1~4** | 그 창이 카드 자리에서 날아와 가운데에 뜨고, 지금 창은 사이드바로 들어감 |
| 카드를 끌어 화면 가운데에 놓기 | 지금 창은 그대로 두고, 놓은 자리에 그 창을 원래 크기로 함께 띄움 |
| 카드 우클릭 | **탭 고정**(항상 사이드바 위쪽에 유지, 재시작 후에도 유지) / **창 닫기** |
| 창 최소화 (버튼, Win+D, 네 손가락 아래로 쓸기) | 창이 제자리에서 사이드바로 빨려 들어감 |
| Alt+Tab, 작업 표시줄, 새 창 열기 | 이전 창이 사이드바로 들어감 |
| 전체화면 앱(게임, 영상) | 사이드바가 왼쪽으로 미끄러져 숨고 단축키도 앱에 양보, 끝나면 다시 나옴 |
| 가상 데스크톱 전환 | 데스크톱마다 그 데스크톱의 창만 사이드바에 표시 |
| 트레이 아이콘 우클릭 | Windows 시작 시 실행, 종료 |

사이드바에는 데스크톱마다 최근 4개 창이 보입니다. 최소화된 채로 시작한 창은 앱 아이콘과 제목이 있는 대체 카드로 보이다가, 한 번 화면에 나오면 실제 모습으로 바뀝니다.

## 자원 사용

"있는지 없는지 모를 정도"를 목표로 만들었습니다. 측정값은 Windows 11, AMD 내장 그래픽 기준입니다.

| 상태 | CPU | GPU | 메모리 |
|---|---|---|---|
| 대기 (20초 측정) | 0% (0.000초) | 0% | 작업 관리자 기준 약 1MB, GPU 메모리 약 27MB |
| 창 전환 1회 | 약 60ms (0.5초 동안) | DWM이 애니메이션 처리 | 변화 없음 |

- 순수 Win32 + C++/WinRT + `Windows.UI.Composition`. 런타임 설치 없이 exe 하나(약 360KB)로 동작합니다.
- 애니메이션은 모두 Composition 키프레임이라 DWM(화면 합성기)이 GPU로 실행합니다. 앱은 그리기 루프가 없습니다.
- 창 썸네일은 실시간이 아니라, 창이 사이드바로 들어갈 때 `Windows.Graphics.Capture`로 **한 장만** 찍은 스냅샷입니다.
- 창 변화 감지는 이벤트 훅(포커스, 최소화, 셸 훅)만 쓰고 타이머나 폴링이 없습니다.
- 평소에는 사이드바 영역만 덮고, 전환하는 동안에만 화면 전체로 커집니다.

## 설치

[Releases](https://github.com/ilfpns/Mulddungddunge/releases) 또는 직접 빌드한 `dist\` 폴더에서:

- **`StageManager-<버전>-win64.exe`**: 설치형. 관리자 권한 없이 `%LOCALAPPDATA%\Programs\StageManager`에 설치하고, 시작 메뉴와 "설정 > 앱"에 등록합니다. 제거도 "설정 > 앱"에서 할 수 있습니다.
- **`StageManager-<버전>-portable.zip`**: 압축을 풀고 `stage-manager.exe`를 실행합니다.

## 빌드

필요한 것: Visual Studio 2022 이상(C++ 데스크톱 개발 워크로드), Windows SDK 10.0.22621 이상.

```bat
build.bat                                   :: bin\stage-manager.exe
powershell -ExecutionPolicy Bypass -File packaging\package.ps1   :: dist\ 에 설치형 exe와 zip
```

`build.bat`은 vswhere로 Visual Studio를 찾아 `cl.exe` 한 번으로 빌드합니다. 컴파일러 임시 파일은 `obj\tmp`에 만들고, 오류 위치 조회용 `obj\stage-manager.map`도 생성합니다.

## 구조

```
src/
  main.cpp           진입점, 단일 인스턴스, 크래시 처리기
  Stage.*            사이드바, 카드, 전환/드래그/최소화 애니메이션, 메뉴, 단축키, 이벤트 처리
  Snapshot.*         D3D/D2D 장치, 1프레임 창 캡처, 아이콘, 대체 카드, 텍스트
  WindowTracker.*    관리 대상 창 판별, 창 위치/복원 위치, 프로세스 경로
  AppBar.*           화면 가장자리 예약(AppBar)과 전체화면 알림
res/                 아이콘, 버전 정보(version.h), 매니페스트
packaging/           설치/제거 스크립트, 패키지 빌드 스크립트
docs/QA.md           QA 체크리스트
```

## 문제 해결

- **최소화 애니메이션이 사라졌어요**: 앱은 실행 중에 Windows 기본 최소화 애니메이션을 끄고 종료할 때 되돌립니다. 원래 값은 `HKCU\Software\StageManager\MinAnimate`에 보관해서, 비정상 종료되더라도 다음 실행이나 설치/제거 때 복구합니다.
- **오류 기록**: `%TEMP%\stage-manager.log`. 크래시가 나면 `rva=0x...`가 남고, `obj\stage-manager.map`에서 그 주소의 함수를 찾을 수 있습니다.
- **자세한 이벤트 추적**: 빈 파일 `%TEMP%\stage-manager.trace`를 만든 뒤 앱을 시작하면 포커스, 최소화, 데스크톱 전환, 고정 이벤트가 그 파일에 기록됩니다. 파일을 지우고 다시 시작하면 꺼집니다.

## 알려진 제한

- 주 모니터만 관리합니다.
- 지금은 사이드바가 화면 왼쪽을 예약(AppBar)해서, 최대화한 창이 그 폭만큼 좁아집니다. 창이 사이드바를 덮으면 사이드바가 왼쪽으로 숨고 화면 왼쪽 끝에 마우스를 대면 나오는 방식으로 바꾸는 중입니다.
- 관리자 권한으로 실행된 창은 일반 권한인 이 앱이 최소화/복원할 수 없습니다(Windows UIPI).
- 항상 위에 떠 있는 창(데스크톱 펫, PIP 플레이어 등)은 관리하지 않습니다.
