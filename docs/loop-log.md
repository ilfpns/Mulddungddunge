## 2026-10-01 엣지 케이스 수색·보완, 반응 속도 170ms 미만

### 목표
- PC 점유율 영향 1% 미만
- 카드 반응(띄우기, 내리기, 우클릭, 윈도우 전환) 170ms 미만
- 엣지 케이스 5개 이상 찾아 보완

### 엣지 케이스
| # | 증상 | 원인 | 보완 |
|---|---|---|---|
| 1 | 카드가 날아가는 중 다른 카드를 누르면 무시됨 | 전환 중에는 마우스 누름 자체를 기록하지 않음 | 누름은 항상 기록, 전환 중 클릭은 대기열에 두고 전환이 끝나면 실행 (1.2초 넘으면 버림) |
| 2 | 전환 중 우클릭이 무시됨 | `WM_RBUTTONUP`을 전환 중이면 버림 | 대기열에 두고 전환이 끝난 뒤 같은 카드의 메뉴를 엶 |
| 3 | 작은 화면에서 "크기 맞추기" 창이 화면 밖으로 나감 | 저장된 고정 크기(2560×1440 기준)를 그대로 사용 | 가장 가까운 모니터 작업 영역 안으로 줄이고 옮김 (`FitFrame`) |
| 4 | 터미널 탭을 바꿔도 카드 아이콘이 예전 셸 | 다시 쓰는 카드의 아이콘을 새로 확인하지 않음 | 카드가 돌아올 때 터미널이면 아이콘을 다시 그림 |
| 5 | 스피커 표시가 엉뚱한 앱 카드에 붙을 수 있음 | 오디오 pid → 앱 캐시를 64개가 될 때까지 유지, 종료된 pid를 다른 프로세스가 재사용 | 지금 오디오 세션이 있는 pid만 캐시에 남김 |
| 6 | 절전 해제·드라이버 재시작 후 카드가 비고 캡처 실패 | D3D 장치 손실 처리 없음 | 장치 손실을 감지해 장치를 새로 만들고 카드·아이콘을 다시 그림 (절전 해제, 화면 변경, 감시 타이머 때 확인) |
| 7 | 전환 준비가 오래 걸리면 창 표시도 늦어짐 (최대 172ms) | 조기 표시 타이머를 준비가 끝난 뒤부터 셈 | 클릭 시점부터 세도록 변경 |
